# Observability files

Prometheus alert rules, Grafana dashboards and an OpenTelemetry Collector
example for SRT Telemetry. See
[Alert rules and Grafana dashboards](../docs/architecture/alerting.md) and
[OTLP export](../docs/architecture/otlp.md).

Quick start with the embedded server on port 9810:

1. Prometheus: copy `prometheus/prometheus.yml` and
   `prometheus/srt-telemetry-alerts.yml` next to each other, set the targets,
   and start Prometheus.
2. Grafana: import `grafana/dashboards/srt-fleet.json` and `srt-endpoint.json`,
   or copy `grafana/provisioning/` into Grafana's provisioning directory and
   point the dashboard provider's `path` at `grafana/dashboards/`.
3. Open **SRT fleet**.

To try it without a real deployment, run the dashboard demo
(`robotweax_srt_telemetry_public_srt_dashboard_demo --port 9810`), which runs
real SRT streams through impaired paths.

The dashboards are generated by `grafana/build_dashboards.py`; edit it and
run it instead of editing the JSON. `tools/check_dashboards.py` and
`tools/observability_e2e.py` test everything here.
